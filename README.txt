【是什么】
一个纯本地运行的电脑体检工具，双击即用，不联网、不上传数据。
运行后会扫描你的电脑硬件配置、温度、硬盘健康、蓝屏记录，
生成一份你能看懂的 HTML 体检报告。

【怎么用】
1. 确保你在 Windows 电脑上（Win10/Win11）
2. 右键 PC-Doctor-Lite.exe → 「以管理员身份运行」
   （不用管理员也能跑，但读不到温度和部分日志）
3. 等待 10~30 秒，自动弹出体检报告（浏览器打开 HTML）
4. 报告保存在：C:\Users\你的用户名\AppData\Local\Temp\PC-Doctor-Lite-Reports\

【报告包含什么】
✅ 综合健康评分（0~100 分，绿/黄/红三档）
✅ 硬件配置清单（CPU/内存/显卡/硬盘）
✅ 实时温度（CPU/主板/GPU，超温标红）
✅ 磁盘空间使用率（带可视化进度条）
✅ 蓝屏记录（最近 5 次 dump 文件）
✅ 每个人话解释 + 优化建议

【集成工具说明】
本工具调用以下开源/免费工具增强检测能力：
- BlueScreenView (NirSoft)  ：解析蓝屏 minidump 文件
- CrystalDiskInfo (MIT)     ：读取硬盘 S.M.A.R.T. 健康数据
- psutil (BSD)              ：系统信息采集
- WMI (Windows)             ：硬件信息读取

上述工具版权归原作者所有，本工具仅做集成调用。

【为什么需要管理员权限】
Windows 默认禁止普通程序读取硬件传感器和系统日志。
以管理员身份运行才能：
- 读取 CPU/主板/GPU 温度
- 读取蓝屏 minidump 文件
- 读取完整的内存条信息

【常见问题】
Q：杀毒软件报毒？
A：PyInstaller 打包的程序常被误报。本工具开源透明，
   可放心使用。如不放心，可用源码自行打包。

Q：和鲁大师什么区别？
A：三个字——不流氓。不弹窗、不捆绑、不偷偷上传数据、
   不诱导安装全家桶。跑完就走，不留痕迹。

Q：支持 macOS / Linux 吗？
A：目前仅支持 Windows。Mac/Linux 版本开发中。

Q：会修改我的系统吗？
A：不会。纯只读扫描，不改任何系统设置、不写注册表。
