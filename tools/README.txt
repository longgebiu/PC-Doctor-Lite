Tools Directory
===============

这个目录用于存放第三方开源/免费工具的可执行文件。
PC-Doctor-Lite 会在运行时调用这些工具增强检测能力。

需要手动下载并放入以下文件：

1. BlueScreenView.exe
   来源：https://www.nirsoft.net/utils/bluescreenview.zip
   用途：解析 Windows 蓝屏 minidump 文件
   协议：NirSoft Freeware（免费软件，不可商业再分发）

2. CrystalDiskInfo.exe（便携版）
   来源：https://crystalmark.info/en/software/crystaldiskinfo/
   用途：读取硬盘 S.M.A.R.T. 健康数据
   协议：MIT License
